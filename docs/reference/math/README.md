# Math Reference

This directory routes to the fixed-width math contracts.

## Contents

- [`math32/docs`](../../../math32/docs/README.md) owns math32 behavior.
- [`math64/docs`](../../../math64/docs/README.md) owns math64 behavior.

The C++ `math32.contract` and `math64.contract` executables are the executable
authority. Compiler output inspection and benchmarks are focused investigations,
not part of the permanent repository test suite.
