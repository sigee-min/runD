# Security policy

## Supported versions

runD is currently an alpha project. Security fixes are applied to the latest
published release only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do
not open a public issue for a suspected vulnerability.

Include the affected version and platform, the impact, reproduction steps or a
minimal proof of concept, and any suggested mitigation. A maintainer will
acknowledge the report and coordinate disclosure through the private advisory.
