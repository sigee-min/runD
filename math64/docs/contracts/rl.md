# Math64 RL Contract

Math64 RL owns high-precision vector recurrence helpers: `Bellman`, `TdError`,
`QUpdate`, `ReturnStep`, and `GaeStep`. These compose fixed multiply and
saturating arithmetic from the math64 SIMD lane law.

Element scalar values are storage and test literals only; they are not public
formula contracts or fallback modes.

Evidence: `math64.contract`.
